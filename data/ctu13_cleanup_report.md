# CTU-13 Dataset Analysis and Safe Cleanup Report

## Executive Summary

This report provides an in-depth provenance and storage evaluation of the CTU-13 Botnet Dataset in NEXUS-Forecast.
The role of CTU-13 in NEXUS-Forecast is strictly for **optional independent validation, botnet/C2 temporal behavioral forecasting, and cross-dataset generalization**.
The NEXUS-Forecast world model operates on flow-level temporal states rather than raw packet payloads.

## Policy & Recommendations

### 1. Files Recommended to KEEP (Total: 26 files, ~2.54 GB)
- **13 `.binetflow` files**: Bidirectional flow records generated by Argus with ground truth botnet labels (`Normal`, `Botnet`, `Background`). These serve as the input sequences for temporal flow modeling.
- **13 `README` / `README.html` files**: Human and machine readable documentation describing network topology, infected IP addresses, command-and-control servers, and runtime execution timelines.

### 2. Files Recommended to DELETE (Total: 13 files, ~71.72 GB)
- **13 `.pcap` files**: Very large packet captures totaling **77,009,987,473 bytes (71.72 GB)**. In particular, Scenario 10 (`botnet-capture-20110818-bot.pcap`) consumes **70.68 GB (65.83 GiB)** alone, and Scenario 11 consumes **4.26 GB**.
- **Safety Replacement**: Each of these 13 PCAP files has been verified to possess a corresponding, readable, and non-empty `.binetflow` file in the same directory.

### 3. Files Classified as REVIEW_REQUIRED (Total: 10 files, ~9.12 MB)
- **10 `.exe` malware binaries**: Original malware executables (`Neris.exe`, `rbot.exe`, `svchosta.exe`, etc.) captured in the CTU environment. While small (9.12 MB total), they are not flow datasets nor raw PCAP. Per safety rules, they are categorized as `REVIEW_REQUIRED` and will **NOT** be deleted.

## Disk Space Recovery Estimate

- **Current CTU-13 Footprint**: 74.27 GB
- **Disk Space Recovered by Deleting 13 PCAPs**: **71.72 GB (77,009,987,473 bytes)**
- **Retained CTU-13 Footprint**: 2.54 GB flow data + 8.71 MB malware samples
- **Storage Reduction**: **96.57%** reduction in CTU-13 storage consumption

## Risk Analysis & Technical Limitations

> [!WARNING]
> **Limitation of Deleting Raw PCAP**:
> Deleting the raw PCAP files permanently removes the ability to perform future packet-payload inspection, deep application-layer protocol re-dissection, or re-extraction of alternative flow feature sets via updated flow extractors (such as CICFlowMeter or Zeek) directly from this scenario's packets.
>
> **Mitigation for NEXUS-Forecast**:
> For the objectives of NEXUS-Forecast (temporal state prediction, attack-stage forecasting, botnet C2 behavior transition modeling), the retained `.binetflow` representations already contain complete bidirectional flow duration, protocols, IP addresses, port pairs, packet counts, byte counts, and verified ground-truth labels. The PCAPs are therefore redundant for flow-level temporal modeling.
